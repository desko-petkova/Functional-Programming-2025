# Функционален подход в C#

Функционалното програмиране се фокусира върху използването на функции като основни градивни елементи, 

минимизиране на страничните ефекти и работа с неизменяеми данни.



Основни принципи:

&nbsp;	- функции като стойности (first-class functions);

&nbsp;	- липса или минимизиране на странични ефекти;

&nbsp;	- използване на Func, Predicate, Action;

&nbsp;	- композиция на функции;

&nbsp;	- рекурсия вместо цикли;

&nbsp;	- чисти функции (pure functions);

&nbsp;	- неизменяемост на данните (immutability);



## 1. Функции като стойности (First-class functions) - В C# това се реализира чрез делегати.



###  Func<T>, Func<TInput, TOutput>



Функциите се третират като обикновени стойности:

&nbsp;	- могат да се присвояват на променливи;

&nbsp;	- могат да се подават като аргументи;

&nbsp;	- могат да се връщат като резултат;

---------------------------------------------------

Примери:

&nbsp;	Func<int, int> f = x => x \* 2;

&nbsp;	Func<string, int> length = s => s.Length;

&nbsp;	Func<int> func42 = () => 42;

-----------------------------------------------------

###  Predicate<T> Функция, която връща bool — използва се за условия и филтриране.

---------------------------------------------------

Примери:

&nbsp;	Predicate<int> isEven = x => x % 2 == 0;

&nbsp;	nums.FindAll(isEven);

---------------------------------------------------

###  Action<T> Функция без резултат (void) - почти винаги e страничен ефект.

--------------------------------------------------------

Примери:

&nbsp;	Action<int> print = x => Console.WriteLine(x);

&nbsp;	Action<int> addToList = x => list.Add(x);

---------------------------------------------------------

## 2. Генерични функции и числови типове - C# позволява създаване на универсални числови функции чрез INumber<T>.

------------------------------------------------------------

Пример:

&nbsp;	static T MultyNum<T>(T x, T y) where T : INumber<T>

&nbsp;	=> x \* y;

------------------------------------------------------------

Предимства:

&nbsp;	- работи с всички числово типове (int, double, decimal, float, т.н.);

&nbsp;	- елиминира дублирането на код;



## 3. Композиция на функции (Function Composition)



### Генеричната функция комбинира две функции в една:

---------------------------------------------------	

static Func<T3, T2> Compose<T1, T2, T3>

(

&nbsp;   Func<T1, T2> f,

&nbsp;   Func<T3, T1> g

)

{

&nbsp;   return x => f(g(x));

}

----------------------------------------------------

Видове композиция:

&nbsp;	- Хомогенна — всички функции имат еднакъв вход/изход.

&nbsp;	- Хетерогенна — типовете могат да се различават.



## 4. Чисти функции (Pure Functions)



Характеристики:

&nbsp;	- без I/O операции;

&nbsp;	- без достъп до външно състояние;

&nbsp;	- детерминирани — винаги връщат един и същ резултат при едни и същи аргументи.



## 5. Неизменяемост (Immutability)

Работи се с нови обекти, вместо да се променят съществуващи.



Предимства:

&nbsp;	- по-малко странични ефекти;

&nbsp;	- по-лесно тестване;

&nbsp;	- безопасност при паралелно изпълнение.



## 6. Рекурсия вместо цикли - Функционалният стил предпочита рекурсия.



### Обикновена рекурсия:

&nbsp;	int Sum(int n) => n == 0 ? 0 : n + Sum(n - 1);

-------------------------------------------------------------

### Опашкова рекурсия:

&nbsp;	int SumTail(int n, int acc = 0) 

&nbsp;		=> n == 0 ? acc : SumTail(n - 1, acc + n);
